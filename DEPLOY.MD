# ⚙️ Framework Settings

> Cấu hình triển khai dự án Next.js (Deployment Settings) trên các dịch vụ Hosting / PaaS (như Vercel, Render, Railway, Coolify, Koyeb...).

| Setting | Value | Override |
| :--- | :--- | :---: |
| **Framework Preset** | `Next.js` | — |
| **Build Command** | `pnpm build` | `ON` 🔵 |
| **Output Directory** | `Next.js default` | `OFF` ⚪ |
| **Install Command** | `pnpm install --no-frozen-lockfile` | `ON` 🔵 |
| **Development Command** | `next dev --port $PORT` | `ON` 🔵 |
